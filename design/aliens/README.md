# Alien artwork (local only)

The selector shows each alien as a hologram. To use real artwork, drop images here
named after the alien's slug. Use PNG with a transparent background for the best
hologram; WebP and JPG also work.

```
heatblast.png    xlr8.png        four-arms.png   grey-matter.png
diamondhead.png  ripjaws.png     upgrade.png     ghostfreak.png
stinkfly.png     wildmutt.png    cannonbolt.png  echo-echo.png
clockwork.png
```

Everything in this folder except this README is **gitignored**. Official Ben 10 art
is copyrighted, so keep it on your machine and off the public repo. If an image is
missing, the prototype falls back to the original glyph.
